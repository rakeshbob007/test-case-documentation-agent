01 Complete overview

What this agent does

The Test Case Documentation Agent is a self-hosted tool that converts a demonstrated application workflow — either a screen recording or a plain-English step guide — into a formal, client-ready Word (.docx) test case document.

Instead of a QA engineer manually watching a workflow, writing steps, taking screenshots, cropping/pasting them into a table, and formatting a document by hand, this agent automates the entire chain:

1. Capture

Upload a video, record one in-app, or type the steps in plain English.

2. Understand

Claude reads the video frames, or drives a real browser through the typed steps itself.

3. Author

Functional test cases, or functional + edge/negative cases.

4. Produce

A Word document matching the QA team's own template, with real screenshots as evidence.

It runs entirely on the user's own machine using the user's own Claude subscription — no server, no SaaS fee, and no workflow data leaves the laptop except the Claude API calls themselves.

Key design decisions

  • Local-first, no server — Streamlit on localhost:8501 plus a small local HTTP server for the recorder.
  • Claude Code as the reasoning + authoring engine, invoked headlessly via a project-local native claude.exe binary — sidesteps Windows PATH/shim and corporate-security restrictions on the global npm install location.
  • Two capture paths, one prompt builder — video frames or a live Playwright session both feed pipeline.build_prompt(). Playwright runs via a locally-pinned @playwright/mcp dependency (not npx ...@latest), so no registry round-trip on every generation.
  • Template-matching — Claude replicates an uploaded reference .docx's exact structure, or falls back to a clean standard table.
  • Built-in recorder — a floating control panel using the browser's native MediaRecorder/getDisplayMedia APIs, handed off to the main app via a polled pointer file.

04 Advantages

Manual authoring vs. this agent

Manual-side figures reflect real-world, live-project experience — swap in your own team's actuals as you track more generations.

4–8 hrsmanual, real-world (half–1 full day)
5–10 minwith this agent
95–99%time saved
~3.8–7.8 hrssaved per document

That manual half-day-to-full-day covers replaying/studying the workflow, writing each step, capturing and placing screenshots, formatting into the team's template, and review — all of it collapses into one ~5–10 minute generation run with this agent.

Cost angle: at a loaded QA rate of roughly $25–$40/hr, ~4–8 hrs saved per document ≈ $100–$320 saved per document. At ~20 documents/month, that's ~$2,000–$6,400/month, ~$24,000–$76,800/year in reclaimed engineer time — against $0 licensing cost.

Non-monetary advantages

  • Consistent formatting every time — no per-engineer style drift.
  • Evidence screenshots are never forgotten or mismatched to the wrong step.
  • Frees QA engineers for test design and exploratory testing.
  • Fully private/local — no workflow data leaves the machine except calls to Claude itself.
05 Features

Complete features, end to end

JIRA ID (optional)

Stamped into the generated document as a label/ID prefix. No live JIRA connection required.

Reference template upload

Claude replicates the uploaded .docx's exact structure and headers, only filling in content.

Video Upload mode

mp4/mov/avi/mkv/webm supported; adjustable 5–40 sampled frames.

Manual Step Guide mode

Claude drives a real Playwright browser, highlighting and screenshotting each interacted element. Headless or headed.

Built-in screen recorder

Floating Start/Pause/Stop panel; finished recording auto-populates the main page within seconds.

Additional guidelines

Free-text instructions layered on top of either workflow source.

Test case scope control

Functional-only, or functional + edge/negative cases.

Output folder picker

Native OS folder-browse dialog (runs in its own isolated process for reliability) or manual path entry, validated before generation.

Live progress bar

Streams progress from the underlying headless Claude Code CLI run, ending in a success message and a download button.

Automatic image fitting

Screenshots resized to fit table cells; document auto-switches to landscape if needed.

Polished terminal-style UI

A live-typing hero prompt, a pulsing status glow, and scanning section dividers.
